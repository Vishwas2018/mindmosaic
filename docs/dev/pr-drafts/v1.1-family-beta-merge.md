## Rollback plan

1. After merging, immediately tag the merge commit:
   ```
   git tag v1.1-beta-rc1 <merge-sha>
   git push origin v1.1-beta-rc1
   ```
2. If a critical issue surfaces in family use: re-point `main` to the pre-merge SHA (`9376d98` v1.0.0) via a revert commit, or use GitHub's "Revert" button on the PR.
3. The `v1.1-beta-rc1` tag preserves the state for forensic diff regardless of what happens to `main`.
